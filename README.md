# Cantera de preguntas

Herramienta del departamento de Filosofía (IES Martín de Bertendona) para generar preguntas tipo test a partir de una lista de conceptos con sus definiciones, elegir las mejores y exportarlas a un examen (Word / Google Docs), Google Classroom (Forms), Kahoot o Moodle.

Página: https://mikagiuri.github.io/cantera-de-preguntas/

Todo funciona en el navegador: la lista y las preguntas elegidas se guardan solo en el navegador de quien la usa.
